# Sistema de Biblioteca
## Descripción
Este proyecto consiste en el desarrollo de un Sistema bibliotecario usando **Spring Boot**, donde se representa un sistema básico de biblioteca y tiene como objetivo implementar tres métodos HTTP **GET**, utilizando `@PathVariable` de Spring para recibir un identificador directamente desde la URL.

El proyecto trabaja con tres clases relacionadas:
- **Libro (A):** representa un libro y contiene sus datos principales.
- **Categoria (B):** representa una categoria de la biblioteca y contiene una lista de libros.
- **Biblioteca (C):** representa una biblioteca y contiene una lista de categorías.
---

## Tecnologías utilizadas

- Spring Web
